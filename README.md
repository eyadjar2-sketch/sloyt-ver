Как работает карта
На странице одна цветная карта на MapLibre GL JS со стилем OpenFreeMap Bright. Для типов мест используются разные SVG-значки, близкие точки собираются в счётные кластеры, а нажатие на значок открывает прямо на карте панель с фотографией, названием, краткой информацией и ссылками. Подложка и векторные данные загружаются с публичного сервиса OpenFreeMap по интернету; отдельный API-ключ не требуется. Передвигать карту можно только в пределах области Твери.
