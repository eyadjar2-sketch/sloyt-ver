# Результаты проекта

## 1. Карта без Leaflet и ненастоящих маршрутов — готово
- [x] Одна интерактивная карта создана на MapLibre GL JS; Leaflet и его CSS/JS/изображений в рабочем проекте и итоговом ZIP нет.
- [x] Подложка загружается с цветного стиля OpenFreeMap Bright, выбранного вместо монохромного Positron; вместо заблокированного `tile.openstreetmap.org` не используется растровый endpoint с 403.
- [x] Все точки добавляются из расширяемого JSON, а счётчик отражает текущее количество объектов без обещания фиксированных пяти.
- [x] Камера удерживается в границах Твери через `maxBounds`, `minZoom` и `maxZoom`.
- [x] Вместо непонятных одинаковых кругов используются согласованные SVG-иконки-pin с узнаваемыми силуэтами типов зданий; основные и дополнительные места различаются цветом и понятной легендой.
- [x] Близкие координаты группируются в счётный кластер, который раскрывается при нажатии/увеличении масштаба; реальные координаты мест не меняются.
- [x] Нажатие на иконку открывает непосредственно поверх карты панель места с фотографией, названием, короткой информацией, источником/архивом и переходом к полной карточке или 3D/аудио.
- [x] Ложные линии маршрута, кнопка «Показать маршрут», самостоятельные панельные ссылки на карту и дополнительные карты удалены. Маленькая обязательная атрибуция OpenMapTiles/OpenStreetMap остаётся в контроле MapLibre непосредственно на карте.
- [x] Ошибка сети отображается как короткое понятное сообщение, а коллекция и 3D-блок остаются доступны.

## 2. Одна объединённая коллекция мест — готово
- [x] Тексты замысла, места и архив объединены в один раздел с сортировкой и фильтрами «Стёрто», «Забыто», «Возвращено».
- [x] Карточка места содержит реальные фотографии, название, короткую справку, пометку основного/дополнительного статуса, авторство/лицензию и ссылки на подробный источник/архив, если они есть. Для монастырей сначала показывается историческая фотография, затем современный вид; тот же порядок используется в карточке маркера на карте.
- [x] Объекты можно добавлять через JSON без изменения счётчика или отдельной фиксированной страницы.

## 3. Компактный просмотрщик 3D и аудио — готово
- [x] Удалена повторяющаяся отдельная карточка выбранного места с лишними фотографиями и длинным текстом; остаётся одна область с селектором места, 3D-схемой и аудиоблоком.
- [x] Выбор храма обновляет соответствующую 3D-схему и название аудио.
- [x] Модель схематическая, вращается и масштабируется, не выдаётся за точную архитектурную реконструкцию.
- [x] Реального звука нет; плеер отключён, не показывает выдуманный прогресс и кратко сообщает, что запись появится позже.

## 4. Сокращённая структура — готово
- [x] Сохранены короткий первый экран и уже выбранная выразительная тема сайта; мобильный первый экран сокращён, чтобы карта была видна раньше.
- [x] Удалены отдельные секции «Замысел», «Архив», «Источники» и панели маршрута. Отдельная панель экскурсий и контактов была возвращена по просьбе пользователя в виде раздела с формой записи и областью контактов; лишней последней панели сайта нет.
- [x] Источники и архивные ссылки остаются только рядом с соответствующими карточками; атрибуции лицензий фотографий сохранены.

## 5. Проверенные данные и эмблема — сохранено
- [x] Сохранены название «Культурный слой Твери», переданная пользователем эмблема и проверенные данные существующих мест.
- [x] Фотографии соответствуют местам; подписи, авторство/лицензии, архивы и источники сохранены на карточках.
- [x] Спорные даты, адреса и режим посещения не превращены в неподтверждённые гарантии.

## 6. Описание проекта и речь для защиты — готово

- [x] В описании явно указаны границы проекта: модели схематические, аудиозаписи пока не добавлены, карта и веб-шрифты требуют интернет-соединения.

- [x] В разделе есть место для контактных данных проекта и форма с полями имени, телефона/мессенджера, желаемой даты, числа гостей и пожеланий.
- [x] Макет формы сообщает, что заявка пока не отправляется. Реальный телефон, e-mail или мессенджер не выдумывается; для настоящей записи нужны контакты владельца проекта.
