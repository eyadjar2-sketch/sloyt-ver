# Обновлённый план сайта

## Задача и поведение

Упростить статический путеводитель «Культурный слой Твери» для GitHub Pages. Сайт представляет расширяемую коллекцию мест города, а не маршрут с фиксированным количеством объектов. Счётчики и коллекция динамически строятся из JSON; заголовки не обещают «пять храмов».

Свести страницу к четырём понятным областям после короткого первого экрана: одна цветная интерактивная карта Твери; объединённая сортируемая и фильтруемая коллекция; компактный просмотрщик 3D и аудио; раздел экскурсий с контактной областью и демонстрационной формой записи. Удалить самостоятельные разделы «Замысел», «Места», «Архив», глобальные источники и отдельную карточку выбранного места. Для монастырей показывать архивный вид первым, современное фото вторым и в коллекции, и в панели карты; в остальных карточках оставить фото, название, короткую информацию, слой и ссылку на источник/архив, если они есть.

Карту полностью перевести с Leaflet на MapLibre GL JS. Использовать цветной публичный векторный стиль OpenFreeMap Bright вместо монохромного Positron; библиотеки MapLibre, её worker и Three.js хранить локально, чтобы не зависеть от CDN. Сам стиль и данные подгружаются из OpenFreeMap по HTTPS; пользовательский API key не требуется. Стандартный источник тайлов OpenStreetMap, отдающий 403, убрать. Указать bounds Твери, ограничить pan и zoom. Все точки берутся из `places.json`. Вместо непонятных кружков использовать красивые согласованные SVG-иконки-pin с простыми узнаваемыми силуэтами типа здания для каждой точки; основные и дополнительные храмы различать цветом и легендой. Близкие объекты группировать в счётный кластер и раскрывать при нажатии/увеличении, не меняя реальные координаты. Нажатие на иконку открывает поверх карты панель места с фотографией, названием, краткой информацией, источником/архивом и переходом к полной карточке или 3D/аудио.

Убрать полностью выдуманные маршрутные линии, кнопки прокладки маршрута и описание переходов. Никакое прямое соединение GPS-точек не представляется пешеходной навигацией. Удалить отдельные ссылки/панели OpenStreetMap внизу страницы. Сохранить лишь небольшую обязательную атрибуцию источников, которую MapLibre показывает из стиля прямо в углу карты; не скрывать её контролами. При сбое стиля или тайлов пользователь увидит короткое понятное сообщение, остальной контент останется доступен.

Коллекция мест соединяет прежние тематические тексты, карточки и архив. В ней один экземпляр карточки на объект: реальное фото, подпись с автором и лицензией, название, короткий lead, слой «Стёрто/Забыто/Возвращено», статус «основное/дополнительное», ссылка на лучший источник и, если есть, архивное изображение. Предусмотреть фильтрацию по историческому слою и сортировку по приоритету, названию и наличию архива. Для добавления объектов достаточно строки в JSON.

Вместо отдельной панели «выбранное место» оставить один компактный 3D/audio-viewer с селектором. Выбранное место обновляет 3D-схему и заголовок аудиоблока. Модель остаётся иллюстративной, с перетаскиванием/масштабом. Аудиофайлы сейчас не создаются и не воспроизводятся; аккуратная кнопка запуска отключена, рядом короткая правдивая подпись о будущем появлении записи, без «макета» и выдуманного прогресса.

Сохранить выразительный городской атлас и пользовательский логотип, но сократить повторяющиеся тексты и визуальные элементы. После 3D/audio разместить компактный раздел экскурсий с контактной областью и макетом записи; не добавлять отдельную нижнюю панель.

## Технический подход

Обычная статическая страница: HTML, CSS, JSON и JavaScript, без сервера, базы данных или секретов. `public/index.html` задаёт единственную страницу; `public/styles.css` и `public/atlas.css` — каркас и тему; `public/main.js` загружает коллекцию, строит MapLibre map/source/layers, иконки, кластеры и панель выбранного места, а также управляет сортировкой; `public/model.js` создаёт схемы на локальной Three.js; `public/data/places.json` — расширяемый каталог. Фото и логотип хранятся локально. Векторный style/tiles и Google Fonts требуют интернет-соединения.

`.github/workflows/pages.yml` публикует статический каталог `public/` на GitHub Pages. ZIP включает workflow, `.gitignore`, `.nojekyll`, README, описание проекта с речью для защиты, активы и лицензии; относительные пути должны работать в подпапке репозитория. `public/manus-routes.json` остаётся синхронизирован с единственной страницей.

## Структура проекта

- `public/index.html` — первый экран, единственная карта, единая коллекция, просмотрщик 3D/аудио.
- `public/styles.css`, `public/atlas.css` — общие стили, цветная карта, парные фото, карточки экскурсий и мобильная тема.
- `public/main.js` — загрузка данных, фильтрация/сортировка, MapLibre, SVG-иконки, кластеры, панель места, галереи «раньше/сейчас» и выбор объекта; обработчик демонстрационной формы записи.
- `public/model.js` — Three.js-схемы и взаимодействие 3D-viewer.
- `public/data/places.json` — названия, приоритет, слои, реальные координаты, тексты, изображения и ссылки.
- `public/assets/` — логотип, реальные фотографии, архивные изображения; `assets/vendor/maplibre/` и `three/` — локальные JS/CSS и лицензии.
- `public/manus-routes.json` — манифест страницы; `.github/workflows/pages.yml`, `README.md` и `.gitignore` — автономный GitHub Pages пакет.

## Дизайн-система

**Движение:** выразительный городской атлас, не копирующий старый сайт пользователя.

**Принципы:** одна карта без фальшивой навигации; понятные точки без сложных храмовых рисунков; короткая справка и источник рядом с фотографией; страницы без повторяющихся блоков.

**Цвет:** глубокий сине-графитовый и светлая бумага с красным/золотым акцентом из пользовательской эмблемы. Подложка карты — цветной OpenFreeMap Bright вместо монохромного Positron; основные и дополнительные метки имеют спокойные, различимые цвета и пояснённую легенду.

**Структура:** краткий hero, выразительная цветная карта, единая коллекция, компактный медиа-блок и запись на экскурсию.

**Взаимодействия:** границы/zoom удерживают карту в Твери; cluster раскрывает близкие точки; нажатие на красивую иконку открывает на карте фотографическую панель храма; фильтры работают только с коллекцией, не создавая новую карту. Модель меняется при выборе объекта. Аудио остаётся отключённым до настоящих записей.

**Типографика и голос:** Cormorant Garamond для заголовков, Golos Text для интерфейса. Текст прямой и короткий. Примеры: «Тверь. Есть что открыть.»; «Места рядом.»

**Знак:** использовать переданную пользователем эмблему без перерисовки.

**Суть бренда:** современный культурный путеводитель по историческим местам Твери; точный, выразительный, доступный.
