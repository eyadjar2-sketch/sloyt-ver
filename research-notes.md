# Технические заметки по карте

## Причина пустой/заблокированной подложки

Во время проверки Preview у `tile.openstreetmap.org` отображались повторяющиеся тайлы `403 Access blocked`. MapLibre, интерактивность и точки работали, но эта raster-подложка была недоступна. Её удалили из конфигурации карты.

## Выбранный провайдер

Используется официальный стиль OpenFreeMap Positron для MapLibre: `https://tiles.openfreemap.org/styles/positron`. Официальная документация OpenFreeMap приводит стиль Liberty в quick start, указывает отсутствие API-ключей/регистрации и сообщает, что их публичный сервер бесплатный без лимита числа запросов на момент проверки; также отдельно предупреждает об отсутствии SLA. Официальная attribution требуется, а для MapLibre автоматически включается из стиля. Перед интеграцией проверены HTTP 200 для Positron JSON и реального векторного тайла Твери. Источники: [OpenFreeMap](https://openfreemap.org/), [Quick Start](https://openfreemap.org/quick_start/).

`tile.openstreetmap.org` и пользовательский API-ключ не используются. Пользовательские фото/логотип, библиотека MapLibre GL JS и Three.js локальны; картографический стиль и данные подгружаются извне. Поэтому карта требует интернета. Если картографический сервис недоступен, интерфейс показывает короткое сообщение и не блокирует галерею/3D.

## Атрибуция

OpenFreeMap использует данные OpenStreetMap и схему OpenMapTiles. Его официальная страница говорит, что атрибуция обязательна и автоматически добавляется MapLibre из map style. Поэтому отдельная нижняя панель/внешняя ссылка на источник карты удалена, но маленькая атрибуция непосредственно в control карты остаётся видимой. Источник: [OpenFreeMap](https://openfreemap.org/).

CARTO raster tiles больше не подходят для бесключевого подключения: официальное FAQ сообщает, что с 25 сентября 2026 года raster tiles не обслуживаются без API key. Для этого пользовательского ZIP отдельный ключ не запрашивался и не встраивался. Источник: [CARTO Basemaps FAQ](https://docs.carto.com/faqs/carto-basemaps).

## Геометрия и поведение

Точки места берутся из каталога `public/data/places.json`. MapLibre ограничивает перемещение заданной областью вокруг Твери и разумными пределами масштаба. Несколько близких точек автоматически группируются в числовой кластер и раскрываются при увеличении, при этом реальные координаты не меняются. Линия между точками удалена: она не была рассчитанным пешеходным маршрутом.
